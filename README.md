# Java: Primeira Aplicação


Primeira aplicação desenvolvida em Java durante o curso 
"Java: criando a sua primeira aplicação" da Alura.

O foco do projeto é colocar em prática os conceitos iniciais da linguagem Java, 
como entrada de dados, estruturas condicionais e repetição.

Foram revisados os conteúdos de:

- Variáveis
- Condicionais
- Laços de repetição
- Orientação a Objetos
